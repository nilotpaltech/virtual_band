# UJAM Mapping Reference

MIDI note mappings for **UJAM Virtual Drummer (VD-Brute)** tailored specifically for **Ableton Live** (where C3 = MIDI Note 60).

---

## 1. Instrument Keys (Individual Drum Hits)

Use these notes to program custom MIDI drum patterns or trigger individual kit elements directly in Ableton's piano roll.

| Note Name (Ableton) | MIDI Note # | Instrument / Sound |
| :--- | :--- | :--- |
| **C1** | 36 | Kick |
| **C#1** | 37 | Sidestick |
| **D1** | 38 | Snare |
| **D#1** | 39 | Snare Rim |
| **E1** | 40 | Tom Lo 1 |
| **F1** | 41 | HH Close |
| **F#1** | 42 | HH Pedal |
| **G1** | 43 | Tom Lo 2 |
| **G#1** | 44 | HH Open |
| **A1** | 45 | Tom Hi |
| **A#1** | 46 | Crash 1 |
| **B1** | 47 | Ride |
| **C2** | 48 | Ride Bell |
| **C#2** | 49 | HH Half |
| **D2** | 50 | Crash 2 |
| **D#2** | 51 | Mute |
| **E2** | 52 | Unmute |

## 2. Style Keys (Grooves, Phrases & Controls)

| Note Range (Ableton) | MIDI Note # | Category | Function / Description |
| :--- | :--- | :--- | :--- |
| **C3 – D#3** | 60 – 63 | **Intros** | Intro pattern variations |
| **C3 – B3** *(Lower)* | 60 – 71 | **Verses** | Main verse phrase variations |
| **E3 – A#3** | 64 – 70 | **Fills** | Fill pattern variations |
| **B3 – D4** | 71 – 74 | **Endings** | Ending pattern variations |
| **C4 – B4** *(Lower)* | 72 – 83 | **Choruses** | Main chorus phrase variations |
| **D#4 – G#4** | 75 – 80 | **Breakdowns** | Breakdown pattern variations |
| **A4 – A#4** | 81 – 82 | **Specials** | Special performance pattern variations |
| **B4** | 83 | **Stop** | Instantly halts phrase playback |
